# Практична робота 1 - Теорія ймовірностей

Цей репозиторій містить матеріали та програмний код для практичної роботи з теорії ймовірностей, присвяченої емпіричному підтвердженню Закону великих чисел (ЗВЧ), методу Монте-Карло та аналізу стохастичних систем.



## Загальна інформація
Дисципліна: Теорія ймовірностей та математична статистика
Тема: Моделювання випадкових подій засобами програмування
Варіант: 4 (Задача про зустріч / Класифікатор)



## Структура репозиторію

```text
pr1-mat/
├── graphics/               # Збережені графіки візуалізації результатів
│   ├── block1_lln.png
│   └── block3_pi_convergence.png
├── report/                 # Звіт про виконання роботи у форматі PDF
│   └── PR1_Report_Процюк_Денис.pdf
├── src/                    # Програмний код симуляцій на Python
│   ├── main.py             # Блоки 1, 3, 4 (ЗВЧ, метод Монте-Карло, AI-модель)
│   └── block2_variants.py  # Блок 2 (Варіант 4: Задача про зустріч)
├── .gitignore              # Файл виключення системного та службового сміття
└── README.md               # Документація проєкту
``` 
## Встановлення та запуск

Встановити Python (якщо ще не встановлено):
Завантажити інсталятор з офіційного сайту: https://www.python.org/downloads/

## Встановити залежності:

```bash
pip install matplotlib
```

## Запустити основний скрипт симуляції (Блоки 1, 3, 4):

```bash
python src/main.py
```
## Запустити симуляцію для Варіанта 4 (Блок 2):

```bash
python src/block2_variants.py
```
